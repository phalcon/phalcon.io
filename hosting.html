Deploy

Where Phalcon runs.

The C extension needs a server where you can install PHP extensions. The pure PHP edition runs anywhere PHP runs.

Phalcon v5: servers you control

Install the C extension on any VPS, cloud or dedicated server where you can install PHP extensions (root or sudo access). For example: AWS EC2, DigitalOcean, Linode, Microsoft Azure.

Follow the installation steps.

Hosts that install Phalcon for you

  • KingHost ↗

    A large host in Brazil with Phalcon on its plans.

Control panels can install it too: cPanel and WHM support Phalcon through EasyApache 4. See shared hosting in the docs.

Phalcon v6: any PHP host

Phalcon v6 runs on any host with PHP 8.1+ and Composer, shared hosting included. There is no extension, and you do not need root access. See installing v6.
