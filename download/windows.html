Get Phalcon · v5

Windows.

Phalcon v5 on Windows is a DLL. Pick the DLL for your PHP, add one line to php.ini, and restart the web server.

Overview Linux/macOS/BSD Windows Composer (v6) IDE Stubs

Want pure PHP, with no extension? Phalcon v6 has the same API.

Install v6 with Composer →

Download

Get the DLLs from the latest GitHub release.

Pick the right DLL

The DLL must match your PHP version, the architecture (x64 or x86) and the thread safety (TS or NTS). phpinfo() shows these values. A wrong DLL does not load.

Install

Add this line at the end of your php.ini file, then restart the web server:

php.ini 
extension=php_phalcon.dll

More details are in the installation guide.

PECL

PECL is deprecated, but it still works. Under Windows it uses the pre-compiled DLLs. Make sure that you have pecl/pear installed.

shell 
pecl channel-update pecl.php.net
pecl install phalcon
