Get Phalcon · v5

IDE Stubs.

The stubs give your IDE and static analysis tools the classes and methods of the C extension.

Overview Linux/macOS/BSD Windows Composer (v6) IDE Stubs

Want pure PHP, with no extension? Phalcon v6 has the same API.

Install v6 with Composer →

IDE stubs are for v5 only. v6 ships PHP source, so your IDE reads it directly.

shell 
composer require --dev phalcon/ide-stubs:^v5.0

To use the stubs with static analysis tools, see static analysis in the docs. The source is in phalcon/ide-stubs.
