Get Phalcon · v6

Composer.

Phalcon v6 is pure PHP. Composer installs it like any other package. There is no extension to compile or enable.

Overview Linux/macOS/BSD Windows Composer (v6) IDE Stubs
$ composer require phalcon/phalcon

Status: release candidate, 6.0.0RC3.

Requirements

PHP 8.1+ and these extensions: fileinfo, json, mbstring, pdo, xml.

Some components need more extensions, for example the PDO driver of your database, or gd or imagick for images.

Next steps

Read the v6 installation guide and the v6 documentation.

You do not need IDE stubs for v6. The framework source is PHP, so your IDE reads it directly.

Prefer the C extension?

Phalcon v5 has the same API and the best speed. See Linux, macOS & BSD or Windows.
