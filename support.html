Get help

Support.

Our great community and contributors are happy to help you! Please use these community resources to get help.

Documentation

Please use the documentation before anything else. You can also use its search to find what you are looking for.

GitHub Discussions

Questions should go to GitHub Discussions: v5 (cphalcon) or v6 (phalcon).

Discord

Come join the Phalcon Discord.

Stack Overflow

Ask a question on Stack Overflow and tag it with phalcon.

Found a bug?

If you still believe that what you found is a bug, open an issue: v5 issues or v6 issues.

Before you post on Stack Overflow

  • Stack Overflow is not dedicated to supporting Phalcon.
  • Please do not report bugs or ask for new features there. Use the issue tracker on GitHub for that.
  • Make sure that you include the 'phalcon' tag with your question.
  • Make sure that you mention 'Phalcon' in the question.

Reporting a bug

Many bugs are raised because users are not running the latest version. Please visit the download page, install the latest version, and confirm that the issue is a bug.

Please report bugs when you have tried all of the above, using the issue tracker on GitHub: v5 or v6.
